# SSMS — SQL Workspace

## Σκοπός
Εκτέλεση SQL στον επιλεγμένο απομακρυσμένο Client, έλεγχος σύνδεσης Back Office και ανάγνωση ή εξαγωγή αποτελεσμάτων.

## Σύντομη περιγραφή
Η καρτέλα διαθέτει SQL editor με αριθμούς γραμμών, απλό χρωματισμό σύνταξης και ένδειξη θέσης. Editor και αποτελέσματα μοιράζονται το διαθέσιμο ύψος μέσω διαχωριστικού που σύρεται. Τα αποτελέσματα εμφανίζονται σε πίνακες με επιλογή result set, κύλιση, αντιγραφή και εξαγωγή CSV.

## Προϋποθέσεις
- Ενημερωμένο Dashboard και ενεργή σύνδεση με τον Server.
- Online Client με το υπάρχον SQL πρωτόκολλο και πρόσβαση στη βάση.
- Διαθέσιμο BOConnection από τα AppSettings του Client.
- Απαιτείται μόνο ενημέρωση Dashboard για τη νέα προβολή· χρησιμοποιούνται τα υπάρχοντα αιτήματα SQL.

## Σημαντικές επισημάνσεις
{% hint style="warning" %}
Το SQL εκτελείται στη βάση που αντιστοιχεί στο επιλεγμένο BOConnection, με τα δικαιώματα της απομακρυσμένης σύνδεσης. Το F5 εκτελεί το επιλεγμένο κείμενο όταν υπάρχει επιλογή, διαφορετικά ολόκληρο το script. Ελέγξτε τον Client, τη βάση και την επιλογή πριν από εκτέλεση εντολών που αλλάζουν δεδομένα.
{% endhint %}

{% hint style="info" %}
Το Stop στέλνει το υπάρχον αίτημα ακύρωσης στον Client. Το UI περιμένει τελικό SQL αποτέλεσμα πριν επιτρέψει δεύτερη εκτέλεση. Η επιβεβαίωση του αιτήματος ακύρωσης δεν αποτελεί από μόνη της τελικό αποτέλεσμα και δεν αναιρεί ήδη ολοκληρωμένες αλλαγές.
{% endhint %}

## Βήματα
1. Ανοίξτε τη διαχείριση του σωστού Client και επιλέξτε **SSMS**.
2. Επιλέξτε **BOConnection**. Η επιλογή συγχρονίζεται με AppSettings και Database.
3. Πατήστε **Test connection** για να δείτε Server, Database, Login, Driver και διάρκεια ελέγχου.
4. Γράψτε SQL ή πατήστε **Open .sql**. Η φόρτωση δεν εκτελεί το αρχείο.
5. Για ολόκληρο το script, αφαιρέστε οποιαδήποτε επιλογή. Για μέρος του script, επιλέξτε μόνο τις επιθυμητές εντολές.
6. Πατήστε **Execute · F5**. Δεν επιτρέπεται δεύτερη εκτέλεση ή δοκιμή σύνδεσης όσο υπάρχει ενεργό αίτημα.
7. Διαβάστε το result set που ανοίγει αυτόματα σε επιτυχή εκτέλεση. Για errors, ανοίγουν τα **Messages**. Τυχόν μερικά αποτελέσματα παραμένουν διαθέσιμα.
8. Σύρετε το διαχωριστικό για μεγαλύτερο editor ή μεγαλύτερο πίνακα.
9. Χρησιμοποιήστε **Copy selected**, **Copy all** ή **Export CSV**. Η εξαγωγή αφορά το επιλεγμένο result set.
10. Με **Save .sql** αποθηκεύστε ολόκληρο το script ως UTF-8, ανεξάρτητα από την επιλογή κειμένου.

## Επεξήγηση πεδίων και ενδείξεων
| Πεδίο | Περιγραφή |
| --- | --- |
| BOConnection | ID και όνομα βάσης από τα ήδη φορτωμένα AppSettings. |
| Timeout (s) | Ακέραιος 1–3600, προεπιλογή 120, που αποστέλλεται στην υπάρχουσα SQL μηχανή του Client. Δεν αποτελεί αυτόνομο χρονόμετρο ακύρωσης του GUI. |
| Ready / Select connection | Έτοιμο UI ή αναμονή επιλογής σύνδεσης. |
| Client offline | Δεν επιτρέπεται αποστολή SQL ή Test connection. Ο editor παραμένει διαθέσιμος. |
| Running · ID | Το BOConnection ID του ενεργού αιτήματος. |
| Stop requested | Έχει ζητηθεί ακύρωση· αναμένεται τελικό αποτέλεσμα. |
| Completed / Error | Τελική κατάσταση, πλήθος γραμμών και διάρκεια όταν παρέχεται. |
| Ln / Col | Γραμμή και στήλη του cursor, μαζί με ένδειξη εκτέλεσης επιλογής ή script. |
| Messages | Σύνοψη, batch errors, rows affected και μηνύματα ορίων. |
| Result N · Batch M | Συγκεκριμένο result set και το batch στο οποίο ανήκει. |
| Περιορισμένα αποτελέσματα | Ο Client επέστρεψε περιορισμένο αποτέλεσμα. Αντιγραφή και CSV δεν ανακτούν επιπλέον γραμμές. |

Ο απλός χρωματισμός δεν ελέγχει τη σύνταξη SQL. Για μεγάλα scripts περιορίζεται στο πρώτο τμήμα των 100.000 χαρακτήρων, χωρίς περιορισμό εκτέλεσης. Το `NULL` εμφανίζεται διακριτά από κενή τιμή.

## Συντομεύσεις
Ισχύουν όταν η εστίαση βρίσκεται μέσα στην καρτέλα SSMS.

| Συντόμευση | Ενέργεια |
| --- | --- |
| F5 / Ctrl+Enter | Εκτέλεση επιλογής ή script. |
| Alt+Break | Αίτημα Stop. |
| Ctrl+T | Test connection. |
| Ctrl+O / Ctrl+S | Άνοιγμα / αποθήκευση SQL αρχείου. |
| Ctrl+B | Εστίαση στην επιλογή BOConnection. |
| Ctrl+R | Εστίαση στην επιλογή result set. |
| ↑ / ↓ στις λίστες | Αλλαγή BOConnection ή result set. |
| Ctrl+M | Άνοιγμα Messages. |
| Ctrl+Shift+P | Εστίαση στον editor. |
| Alt+↑ / Alt+↓ | Μετακίνηση του διαχωριστικού. |
| Ctrl+C σε πίνακα | Αντιγραφή επιλεγμένων γραμμών με επικεφαλίδες. |
| Ctrl+A σε πίνακα | Επιλογή όλων των ήδη εμφανισμένων γραμμών. |
| Ctrl+Shift+C | Αντιγραφή ολόκληρου του επιλεγμένου result set ή των Messages. |
| Ctrl+Shift+E | Export CSV του επιλεγμένου result set. |

## Γραμμή εντολών
Από τον φάκελο `dashboard`, σε PowerShell:

```powershell
python -m app.sql_cli --client CLIENT_CODE --bo-connection 1 --test-connection
python -m app.sql_cli --client CLIENT_CODE --bo-connection 1 --query 'SELECT 1 AS ID;'
python -m app.sql_cli --client CLIENT_CODE --bo-connection 1 --file .\query.sql
python -m app.main --ssms --client CLIENT_CODE --query 'SELECT 1;'
```

Με το console EXE:

```powershell
.\MoonHardRemoteSSMS.exe --help
.\MoonHardRemoteSSMS.exe --client CLIENT_CODE --bo-connection 1 --file .\query.sql
```

Εξαγωγή CSV από CMD:

```bat
MoonHardRemoteSSMS.exe --client CLIENT_CODE --query "SELECT 1 AS ID;" --format csv --result-set 1 > result.csv
```

Η CLI χρησιμοποιεί τις υπάρχουσες ρυθμίσεις Dashboard. Η προεπιλογή output είναι JSON. CSV/TSV περιέχουν ένα result set, από 1. Το CSV γράφεται ως UTF-8 με BOM, όπως η εξαγωγή GUI. `Ctrl+C` ζητά ακύρωση της ενεργής SQL εκτέλεσης και κλείνει την CLI. Η CLI περιμένει έως timeout + 30s για απάντηση· λήξη αναμονής δεν επιβεβαιώνει ότι σταμάτησε η απομακρυσμένη εργασία. Κωδικοί εξόδου: `0` επιτυχία, `1` αποτυχία, `130` διακοπή χρήστη.

## Πότε χρησιμοποιείται / δεν χρησιμοποιείται
Χρησιμοποιείται για ad hoc SQL, scripts με την υπάρχουσα υποστήριξη batches `GO`, διάγνωση σύνδεσης και εξαγωγή επιστρεφόμενων δεδομένων. Δεν αντικαθιστά τον πλήρη Microsoft SSMS, δεν παρέχει IntelliSense ή visual query designer και δεν αλλάζει τον μηχανισμό εκτέλεσης SQL στον Client.

## Έλεγχοι πριν και μετά
Πριν: ελέγξτε Client, BOConnection, επιλεγμένο SQL και δικαιώματα. Μετά: διαβάστε Messages και επιβεβαιώστε κάθε batch, όχι μόνο την τελική ένδειξη. Ελέγξτε αν το αποτέλεσμα έχει περιοριστεί πριν χρησιμοποιήσετε CSV ως πλήρη αναφορά.

## Αντιμετώπιση προβλημάτων
| Σύμπτωμα | Ενέργεια |
| --- | --- |
| Execute ανενεργό | Ελέγξτε online κατάσταση, BOConnection και ενεργό αίτημα. |
| Δεν εμφανίζεται πίνακας | Διαβάστε Messages· μπορεί να μην επιστράφηκε SELECT result set. |
| Αποτελέσματα περιορισμένα | Εξειδικεύστε το query· η εξαγωγή περιλαμβάνει μόνο όσα επέστρεψε ο Client. |
| Stop requested παραμένει | Αναμένεται τελικό SQL αποτέλεσμα από τον Client· η νέα προβολή δεν αλλάζει την απομακρυσμένη μηχανή ακύρωσης. |
| Διακοπή σύνδεσης | Η κατάσταση προηγούμενου SQL είναι άγνωστη. Επιβεβαιώστε την πριν επαναλάβετε εντολή που αλλάζει δεδομένα. |
| Αποτυχία CSV ή Save | Ελέγξτε διαδρομή και δικαιώματα εγγραφής. |

## Συνηθισμένα λάθη
Εκτέλεση μόνο επιλεγμένου τμήματος ενώ αναμένεται ολόκληρο script, επιλογή λάθος βάσης, σύγχυση Stop με rollback και χρήση περιορισμένου CSV ως πλήρους dataset.

## Βέλτιστες πρακτικές
Δοκιμάζετε πρώτα με μικρό SELECT σε δοκιμαστική βάση. Αποθηκεύετε scripts πριν από αλλαγές. Οι νέες ενέργειες UI/CLI καταγράφονται χωρίς SQL κείμενο ή δεδομένα αποτελεσμάτων στα logs.

## Σημειώσεις για μελλοντικές αλλαγές
Editor, αποτελέσματα και κοινή μορφοποίηση είναι ξεχωριστά modules. Νέα λειτουργικότητα πρέπει να διατηρεί συσχέτιση request ID, κοινή επιλογή βάσης και ελέγχους πραγματικών Windows EXE.
