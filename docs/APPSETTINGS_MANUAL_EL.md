# AppSettings — Οδηγός χρήσης

## Σκοπός
Προβολή των ρυθμίσεων του External Tax Provider και επιλογή της σύνδεσης Back Office στο MoonHard Remote Dashboard.

## Σύντομη περιγραφή
Η καρτέλα παρουσιάζει γενικές ρυθμίσεις, επιλεγμένη σύνδεση SQL και διευθύνσεις Provider σε ξεχωριστές κάρτες. Σε μεγάλο παράθυρο χρησιμοποιεί δύο στήλες· σε μικρότερο οι λεπτομέρειες τοποθετούνται διαδοχικά με κατακόρυφη κύλιση. Υπάρχει δεύτερη προβολή με ασφαλές JSON και δυνατότητα αντιγραφής.

## Προϋποθέσεις
- Ενημερωμένο Dashboard και έγκυρες υπάρχουσες ρυθμίσεις σύνδεσης.
- Ο Client έχει διαβάσει και αποστείλει το `appsettings.production.json` στον Server.
- Δεν απαιτείται νέα έκδοση Client ή Server αποκλειστικά για αυτή την αλλαγή του UI.

## Σημαντικές επισημάνσεις
{% hint style="info" %}
Η προβολή χρησιμοποιεί τα τελευταία δεδομένα που έχει αποθηκεύσει ο Server. Η «Ανανέωση προβολής» αναδημιουργεί την εμφάνιση των ήδη φορτωμένων στοιχείων και δεν διαβάζει ξανά το αρχείο στον Client. Για νέα ανάκτηση από τον Server κλείστε και ανοίξτε ξανά τη διαχείριση του Client.
{% endhint %}

{% hint style="warning" %}
Η καρτέλα είναι μόνο για ανάγνωση. Δεν αποθηκεύει αλλαγές στο αρχείο, δεν ελέγχει τη σύνδεση SQL και δεν καλεί τις υπηρεσίες του provider. Κωδικοί, SQL User ID, ClientAuth και Subscription key εμφανίζονται προστατευμένα. Δεν υπάρχει δυνατότητα αποκάλυψης.
{% endhint %}

## Βήματα
1. Επιλέξτε Client στο Dashboard και ανοίξτε τη διαχείρισή του.
2. Ανοίξτε την καρτέλα **AppSettings**.
3. Ελέγξτε την κατάσταση φόρτωσης, τη διαδρομή του αρχείου και την ώρα τελευταίας ανάγνωσης. Η ώρα περιλαμβάνει τη ζώνη ώρας της αποθηκευμένης τιμής.
4. Επιλέξτε **ID και όνομα βάσης** από την αναπτυσσόμενη λίστα.
5. Διαβάστε τις κάρτες **Σύνδεση Back Office** και **Συνδέσεις Provider**.
6. Για αντιγραφή ενός πεδίου, επιλέξτε το κείμενό του και πατήστε `Ctrl+C`. Τα μεγάλα πεδία υποστηρίζουν οριζόντια μετακίνηση με τα βέλη.
7. Επιλέξτε **Ασφαλές JSON** για να δείτε την προστατευμένη αναπαράσταση των γνωστών πεδίων. Δεν πρόκειται για το πλήρες αρχικό αρχείο.
8. Πατήστε **Αντιγραφή JSON** για αντιγραφή της ίδιας αναπαράστασης. Η τρέχουσα επιλογή BOConnection περιλαμβάνεται στο `selected_bo_connection_id`.

## Επεξήγηση πεδίων
| Πεδίο | Περιγραφή |
| --- | --- |
| Επιτρεπόμενα hosts | Αποθηκευμένη τιμή `AllowedHosts`. |
| Μέγιστες επαναλήψεις | Αποθηκευμένη τιμή `MaxRetries`. Το μηδέν εμφανίζεται ως `0`. |
| MaxWaitTimePerInvoice | Η τιμή από το αρχείο, χωρίς μετατροπή ή υπόθεση για τη μονάδα της. |
| Αρχική ημερομηνία | Το `initialDate` μορφοποιείται σε ΗΗ/ΜΜ/ΕΕΕΕ όταν έχει μορφή YYYYMMDD. |
| BOConnection ID | Αναγνωριστικό επιλεγμένης σύνδεσης. |
| SQL Server / Βάση δεδομένων | Στοιχεία από τη σύνδεση SQL του επιλεγμένου BOConnection. |
| UserOID / Email | Αποθηκευμένα στοιχεία της σύνδεσης. |
| SQL User ID / SQL Password | `***` όταν υπάρχουν προστατευμένα στοιχεία· `—` όταν δεν υπάρχουν διαθέσιμα στοιχεία. |
| ClientAuth / Subscription key | Προστατευμένες τιμές· δεν αντιγράφονται τα πραγματικά μυστικά. |
| Σύνδεση SQL | Connection string με απόκρυψη διαπιστευτηρίων. |
| Provider ID | Αναγνωριστικό κάθε ProviderConnection. |
| Base URL / Offline URL | Αποθηκευμένες διευθύνσεις. Τυχόν αναγνωρισμένα credentials στο URL αποκρύπτονται. |

Το `—` δηλώνει ότι δεν υπάρχει διαθέσιμη τιμή. Η επιλογή BOConnection συγχρονίζεται με SSMS, Database και τις συνδεδεμένες προβολές του Manage window.

## Συντομεύσεις
Οι συντομεύσεις λειτουργούν όταν η εστίαση βρίσκεται μέσα στο AppSettings.

| Συντόμευση | Ενέργεια |
| --- | --- |
| Ctrl+R | Ανανέωση προβολής των φορτωμένων στοιχείων. |
| Ctrl+Shift+C | Αντιγραφή ασφαλούς JSON. |
| Ctrl+J | Εναλλαγή Σύνοψης / Ασφαλούς JSON. |
| Ctrl+B | Εστίαση στην επιλογή BOConnection. |
| ↑ / ↓ στη λίστα BOConnection | Αλλαγή της επιλεγμένης σύνδεσης. |
| Ctrl+C σε επιλεγμένο πεδίο | Αντιγραφή της ορατής τιμής. |
| Tab / Shift+Tab | Μετακίνηση μεταξύ των διαθέσιμων πεδίων και χειριστηρίων. |

## Γραμμή εντολών
Από τον φάκελο `dashboard`:

```powershell
python -m app.appsettings_cli --client CLIENT_CODE
python -m app.appsettings_cli --client CLIENT_CODE --list-connections
python -m app.appsettings_cli --client CLIENT_CODE --bo-connection 1
python -m app.main --appsettings --client CLIENT_CODE
```

Με το console EXE:

```powershell
.\MoonHardRemoteAppSettings.exe --help
.\MoonHardRemoteAppSettings.exe --client CLIENT_CODE --bo-connection 1
```

Για ανακατεύθυνση από CMD:

```bat
MoonHardRemoteAppSettings.exe --client CLIENT_CODE > appsettings-safe.json
```

Το EXE χρησιμοποιεί τις υπάρχουσες ρυθμίσεις Dashboard, επιστρέφει προστατευμένο JSON και κωδικό εξόδου `0` σε επιτυχή ανάκτηση, `1` σε αποτυχία. Η απουσία αρχείου δηλώνεται με `file_found: false` και δεν αποτελεί από μόνη της αποτυχία ανάκτησης από τον Server. Για CLI χρησιμοποιήστε το console EXE· το κύριο Dashboard EXE είναι windowed.

## Πότε χρησιμοποιείται / δεν χρησιμοποιείται
Χρησιμοποιείται για διάγνωση της επιλεγμένης βάσης, ανάγνωση παραμέτρων και αντιγραφή προστατευμένων στοιχείων. Δεν χρησιμοποιείται για αλλαγή credentials, επεξεργασία του αρχείου, έλεγχο δικτύου ή αποστολή παραστατικών.

## Έλεγχοι πριν και μετά
Πριν: επιβεβαιώστε τον σωστό Client και την ώρα ανάγνωσης. Μετά την αλλαγή BOConnection: ελέγξτε όνομα βάσης, ID και κοινή επιλογή στις άλλες καρτέλες. Μετά την αντιγραφή: ελέγξτε ότι το JSON περιέχει το αναμενόμενο ID και προστατευμένες τιμές.

## Checklist
- [ ] Η καρτέλα αξιοποιεί το διαθέσιμο ύψος.
- [ ] Η επιλεγμένη βάση συμφωνεί με SSMS και Database.
- [ ] Οι κάρτες παραμένουν προσβάσιμες σε μικρότερο παράθυρο.
- [ ] Τα πεδία επιλέγονται και αντιγράφονται χωρίς δυνατότητα αλλαγής.
- [ ] Τα credentials παραμένουν κρυμμένα και στο JSON.
- [ ] Οι συντομεύσεις δεν επηρεάζουν άλλες καρτέλες.
- [ ] Η CLI επιστρέφει τα ίδια ασφαλή στοιχεία.

## Αντιμετώπιση προβλημάτων
| Σύμπτωμα | Ενέργεια |
| --- | --- |
| Δεν βρέθηκε αρχείο | Ελέγξτε τη διαδρομή στον Client και την εγκατάσταση του provider. |
| Δεν υπάρχουν BOConnections | Ελέγξτε τις ρυθμίσεις στον Client. Οι γενικές ρυθμίσεις παραμένουν ορατές. |
| Δεν υπάρχουν ProviderConnections | Ελέγξτε την αντίστοιχη ενότητα του αρχείου. |
| Παλιές τιμές μετά από Ανανέωση | Περιμένετε νέα αποστολή δεδομένων από τον Client και ανοίξτε ξανά τη διαχείριση. |
| Αποτυχία φόρτωσης | Ελέγξτε σύνδεση Dashboard–Server και logs. Οι προηγούμενες κάρτες καθαρίζονται. |
| CLI: δεν βρέθηκε BOConnection ID | Χρησιμοποιήστε πρώτα `--list-connections`. |

## Συνηθισμένα λάθη
Μην θεωρείτε ότι η επιλογή βάσης αλλάζει το απομακρυσμένο αρχείο. Μην χρησιμοποιείτε το `***` ως πραγματικό password ή API key. Μην θεωρείτε ότι η ύπαρξη URL επιβεβαιώνει ότι ο provider είναι διαθέσιμος.

## Βέλτιστες πρακτικές
Ελέγχετε Client, BOConnection και ώρα ανάγνωσης πριν από διάγνωση. Χρησιμοποιείτε το ασφαλές JSON για τεχνική υποστήριξη και μην επισυνάπτετε το αρχικό αρχείο με credentials. Οι ενέργειες της νέας προβολής καταγράφονται χωρίς τιμές ρυθμίσεων ή JSON.

## Σημειώσεις για μελλοντικές αλλαγές
Νέα πεδία πρέπει να προστίθενται στον κοινό presenter ώστε GUI και CLI να διατηρούν την ίδια πολιτική απόκρυψης. Το Windows workflow ελέγχει πραγματικό UI και τα συσκευασμένα EXE σε καθαρό φάκελο.
