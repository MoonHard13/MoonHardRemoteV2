# MoonHard Remote — Νέο Terminal

## Σκοπός

Μόνιμη απομακρυσμένη συνεδρία CMD/PowerShell με ζωντανή έξοδο και προστατευμένο ιστορικό.

## Σύντομη περιγραφή

Η περιοχή Terminal καταλαμβάνει το διαθέσιμο ύψος. Γράφετε μετά το ενεργό prompt και πατάτε Enter. Δεν υπάρχει ξεχωριστό command input ή κουμπί Send. Η συνεδρία διατηρεί φάκελο και μεταβλητές μέχρι να κλείσει.

## Προαπαιτούμενα

- Ενημερωμένος Server, Client και Dashboard από την ίδια αλλαγή.
- Windows στον Client, με CMD και Windows PowerShell διαθέσιμα.
- Ενεργή σύνδεση Client και αυθεντικοποιημένου Dashboard.
- Για εκτέλεση από source: τα υπάρχοντα requirements του project. Δεν προστίθεται βιβλιοθήκη εφαρμογής.
- Για build: Windows, Python, PyInstaller και οι εξαρτήσεις Dashboard/Client.

## Σημαντικές προειδοποιήσεις

{% hint style="warning" %}
Οι εντολές εκτελούνται με τα δικαιώματα του λογαριασμού που τρέχει τον Client. Αν ο Client είναι υπηρεσία, ο λογαριασμός και ο αρχικός φάκελος μπορεί να διαφέρουν από του συνδεδεμένου χρήστη. Ελέγξτε με `whoami`.
{% endhint %}

{% hint style="warning" %}
Το Stop τερματίζει το shell και τα ενεργά θυγατρικά processes. Μετά χρειάζεται Reconnect. Η διακοπή δεν αναιρεί ενέργειες που έχουν ήδη εκτελεστεί και μπορεί να διακόψει εγγραφές σε αρχεία.
{% endhint %}

{% hint style="info" %}
Η έκδοση υποστηρίζει διαδοχικές γραμμές εντολών σε μόνιμο shell μέσω pipes. Δεν αποτελεί ConPTY emulator: δεν υποστηρίζει πρόσθετο interactive input, εφαρμογές πλήρους οθόνης, PSReadLine ή ANSI cursor controls. stdout/stderr εμφανίζονται στο ίδιο stream. Εκτελέστε `sqlcmd` με `-Q` ή `-i`, όχι σε interactive mode. Χρησιμοποιήστε τις αντίστοιχες μη διαδραστικές επιλογές άλλων προγραμμάτων.
{% endhint %}

## Βήματα χρήσης

1. Επιλέξτε τον Client και ανοίξτε **Manage → Terminal**.
2. Περιμένετε να εμφανιστούν **Connected**, **Ready** και το πραγματικό working directory.
3. Επιλέξτε `cmd` ή `powershell` στην toolbar. Η αλλαγή ανοίγει νέα συνεδρία.
4. Κάντε click μέσα στο terminal και γράψτε μετά το prompt, π.χ. `whoami`.
5. Πατήστε Enter. Η εντολή γίνεται μέρος του προστατευμένου ιστορικού και η έξοδος εμφανίζεται σταδιακά.
6. Μετά την ολοκλήρωση εμφανίζονται νέο prompt, exit code, διάρκεια και τοπική ώρα ολοκλήρωσης του Dashboard.
7. Για διακοπή πατήστε **Stop**. Για νέα συνεδρία πατήστε **Reconnect**.

### Παράδειγμα CMD

```bat
cd /d C:\MoonHard
set MH_TEST=MoonHard
echo %MH_TEST%
dir
```

Εκτελέστε κάθε γραμμή χωριστά. Ο φάκελος και η μεταβλητή διατηρούνται.

### Παράδειγμα PowerShell

```powershell
$test = "MoonHard"
Write-Output $test
Set-Location C:\MoonHard
Get-ChildItem
```

## Επεξήγηση πεδίων και ενεργειών

| Πεδίο / ενέργεια | Λειτουργία |
| --- | --- |
| CMD / PowerShell | Επιλογή shell. Ανοίγει νέα συνεδρία. |
| Working directory | Πραγματικός φάκελος του shell από την τελευταία ολοκληρωμένη εντολή. |
| Connected | Επιβεβαιώθηκε το άνοιγμα της συνεδρίας από τον Client. |
| Running | Εκτελείται εντολή. Η πληκτρολόγηση κλειδώνει μέχρι το αποτέλεσμα. |
| Clear | Καθαρίζει την τοπική προβολή, διατηρώντας συνεδρία, draft και ιστορικό εντολών. |
| Copy | Αντιγράφει όλο το ορατό transcript. |
| Stop | Τερματίζει την εντολή και κλείνει το shell. |
| Reconnect | Ανοίγει καθαρή συνεδρία. Επαναφέρει αρχικό φάκελο και μηδενίζει τις μεταβλητές της προηγούμενης συνεδρίας. |
| Auto-scroll | Ακολουθεί τη νέα έξοδο. Απενεργοποιήστε το για ανάγνωση προηγούμενων αποτελεσμάτων. |
| Exit | Πραγματικός κωδικός ολοκλήρωσης: συνήθως 0 = επιτυχία, 124 = timeout, 130 = Stop. |

### Συντομεύσεις πληκτρολογίου

Οι συντομεύσεις λειτουργούν με εστίαση μέσα στο terminal.

| Συντόμευση | Ενέργεια |
| --- | --- |
| Enter | Εκτέλεση ενεργής εντολής. |
| ↑ / ↓ | Προηγούμενη / επόμενη εντολή και επιστροφή στο αρχικό draft. |
| Tab | Συμπλήρωση αρχείου/φακέλου· επανάληψη για εναλλαγή προτάσεων. |
| Home / End | Αρχή / τέλος ενεργής εντολής. |
| Esc | Καθαρισμός ενεργής εντολής. |
| Ctrl+A | Επιλογή ενεργής εντολής. |
| Ctrl+L | Clear. |
| Ctrl+C | Αντιγραφή επιλογής· χωρίς επιλογή, Stop αν εκτελείται εντολή. |
| Ctrl+Shift+C | Αντιγραφή επιλογής. |
| Ctrl+Shift+A | Copy All. |
| Ctrl+Shift+V | Paste. |
| Ctrl+Shift+R | Reconnect. |
| Ctrl+Shift+S | Εναλλαγή CMD/PowerShell. |
| Ctrl+Shift+L | Εναλλαγή Auto-scroll. |

Το προηγούμενο output επιλέγεται και αντιγράφεται αλλά δεν τροποποιείται. Η επικόλληση πολλών γραμμών μετατρέπει τις αλλαγές γραμμής σε κενά και απαιτεί Enter· δεν εκτελεί αυτόματα scripts.

## Χρήση από CLI/CMD

Από τον φάκελο `dashboard`:

```bat
python -m app.terminal_cli --client CLIENT_CODE --shell cmd --command "whoami"
python -m app.terminal_cli --client CLIENT_CODE --shell powershell --interactive
```

Για διαδοχικές εντολές με CMD μεταβλητές, εκτελέστε από **τοπικό PowerShell** ώστε το `%MH_TEST%` να μη διευρυνθεί τοπικά:

```powershell
python -m app.terminal_cli --client CLIENT_CODE --shell cmd --command 'set MH_TEST=MoonHard' --command 'echo %MH_TEST%'
```

Η επιλογή `--interactive` αφορά διαδοχικές εντολές στο τοπικό CLI και όχι interactive input σε ένα remote πρόγραμμα. `:quit` κλείνει τη συνεδρία, `:clear` καθαρίζει την προβολή και `:help` εμφανίζει βοήθεια. Ctrl+C τερματίζει τη συνεδρία. 

Μετά το build:

```bat
MoonHardRemoteTerminal.exe --client CLIENT_CODE --shell powershell --command "Get-Date"
```

Το console EXE υποστηρίζει ανακατευθύνσεις CMD και το υπάρχον `.env` του Dashboard. Μην περνάτε tokens ως ορίσματα.

## Πότε χρησιμοποιείται / δεν χρησιμοποιείται

Χρησιμοποιείται για διαγνωστικές εντολές δικτύου, υπηρεσιών, αρχείων και συστήματος, καθώς και scripts μίας γραμμής που ολοκληρώνονται χωρίς πρόσθετο input.

Δεν χρησιμοποιείται για interactive `sqlcmd`, nested interactive shells, editors πλήρους οθόνης ή εντολές που περιμένουν επιβεβαίωση. Όριο: 60s ανά εντολή.

## Έλεγχοι πριν / μετά

Πριν: επιβεβαιώστε σωστό Client, Connected, working directory και δικαιώματα με `whoami`. Μετά: ελέγξτε exit code και αποτέλεσμα. Μετά από Stop, timeout, αποσύνδεση ή έξοδο του shell χρειάζεται Reconnect.

## Αντιμετώπιση προβλημάτων

| Πρόβλημα | Έλεγχος / λύση |
| --- | --- |
| Client χρειάζεται ενημέρωση | Ενημερώστε Client· απαιτείται capability `terminal_session_v1`. |
| Δεν εμφανίζεται prompt | Ελέγξτε σύνδεση και ενημέρωση Server/Client· πατήστε Reconnect. |
| Διαφορετικός αρχικός φάκελος | Ο Client τρέχει ως διαφορετικός χρήστης/υπηρεσία. |
| Timeout / Exit 124 | Η εντολή ξεπέρασε τα 60s ή περιμένει input. Χρησιμοποιήστε μη διαδραστική επιλογή. |
| Ελληνικά εμφανίζονται αλλοιωμένα | Το shell χρησιμοποιεί UTF-8. Κάποια παλαιά εργαλεία αγνοούν το code page και παράγουν άλλη κωδικοποίηση. |
| Δεν συμπληρώνεται path | Ελέγξτε δικαιώματα, όνομα και εισαγωγικά σε διαδρομές με κενά. |

## Συνήθη λάθη

Χρήση `cd` χωρίς `/d` για αλλαγή δίσκου στο CMD, αναμονή ότι το Clear κλείνει το shell, εκτέλεση διαδραστικών εντολών ή προσδοκία ότι το Reconnect διατηρεί μεταβλητές.

## Βέλτιστες πρακτικές

Διατηρείτε κοινή έκδοση Server/Client/Dashboard. Ξεκινάτε με μικρές διαγνωστικές εντολές. Χρησιμοποιείτε εισαγωγικά σε paths με κενά. Αποφεύγετε μυστικά στις εντολές και στην έξοδο. Τα logs νέων συνεδριών καταγράφουν ενέργειες/αναγνωριστικά χωρίς command text ή transcript. Ιστορικό: τελευταίες 200 εντολές στη μνήμη. Η προβολή περιορίζεται σε 5.000 γραμμές / 500.000 χαρακτήρες και η έξοδος ανά εντολή σε 60.000 χαρακτήρες.

## Σημειώσεις για μελλοντικές αλλαγές

Επόμενη επέκταση: ConPTY και πλήρης interactive console. Τα source tests περιλαμβάνουν native Windows shell ελέγχους. Το CI ελέγχει τα EXE σε καθαρό directory χωρίς σύνδεση σε πελάτη. Σε Linux οι Windows έλεγχοι παραλείπονται.
