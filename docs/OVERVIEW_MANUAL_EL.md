# Overview — Διαχείριση Client

## Σκοπός
Γρήγορη ανάγνωση στοιχείων και εκδόσεων Client, αλλαγή φιλικού ονόματος και διαχείριση token σύνδεσης.

## Σύντομη περιγραφή
Το Manage ανοίγει απευθείας στις καρτέλες. Το παλιό επάνω πλαίσιο αφαιρέθηκε τελείως και το όνομα παραμένει στον τίτλο του παραθύρου. Το Overview οργανώνεται σε Computer & connection, Application versions, Client name και Security. Σε μεγάλο παράθυρο υπάρχουν δύο στήλες· σε μικρότερο μία στήλη με κύλιση.

## Προϋποθέσεις
- Ενημερωμένο Dashboard και σύνδεση με τον υπάρχοντα Server.
- Για χρήση source, από `dashboard`: `python -m pip install -r requirements.txt`.
- Για την αλλαγή αυτή απαιτείται μόνο ενημέρωση Dashboard.
- Τα στοιχεία προέρχονται από τις τελευταίες αναφορές Client. Offline Client μπορεί να εμφανίζει παλαιότερες εκδόσεις.

## Σημαντικές επισημάνσεις
{% hint style="warning" %}
Το reset token είναι ενέργεια ασφάλειας. Αποσυνδέει τον Client και απαιτεί επανεγγραφή με νέο token. Χρησιμοποιήστε το μόνο όταν χρειάζεται. Πριν το επιβεβαιώσετε ελέγξτε τον Client στον τίτλο του Manage. Απαιτείται πληκτρολόγηση `RESET`.
{% endhint %}

{% hint style="info" %}
Η αποστολή αιτήματος δεν σημαίνει ότι ολοκληρώθηκε. Το UI εμφανίζει επιτυχία όταν λάβει επιβεβαίωση. Αν περάσουν 30s χωρίς απάντηση, η κατάσταση παραμένει ανεπιβεβαίωτη. Ελέγξτε την πραγματική κατάσταση πριν επαναλάβετε ενέργεια.
{% endhint %}

## Βήματα
1. Ανοίξτε **Manage** για τον σωστό Client και επιλέξτε **Overview**.
2. Ελέγξτε κατάσταση, Computer, Windows user, Group και Live connection.
3. Διαβάστε το Last seen στην τοπική ζώνη ώρας του Dashboard, με εμφανές UTC offset.
4. Δείτε τις εκδόσεις MoonHard Client, AMV, Back Office, Tax Provider και Web Service.
5. Για αντιγραφή τιμής, επιλέξτε κείμενο σε πεδίο και πατήστε `Ctrl+C`. Τα πεδία metadata είναι μόνο για ανάγνωση.
6. Το **Copy details** αντιγράφει ασφαλές JSON με τα διαθέσιμα metadata. Δεν περιλαμβάνει tokens, passwords ή connection strings.
7. Στο **Client name**, γράψτε νέο όνομα και πατήστε **Save name** ή `Enter`. Περιμένετε επιβεβαίωση αποθήκευσης.
8. Το **Revert** ή `Esc` στο πεδίο ονόματος επαναφέρει το τελευταίο επιβεβαιωμένο όνομα. Δεν ακυρώνει ήδη αποσταλμένο αίτημα.
9. Αν χρειάζεται reset, πατήστε **Reset client token**, πληκτρολογήστε `RESET` και επιβεβαιώστε. Το dialog ανήκει στο Manage.
10. Περιμένετε αποτέλεσμα reset και επανασύνδεση του Client.

## Επεξήγηση πεδίων
| Πεδίο | Περιγραφή |
| --- | --- |
| Display name | Φιλικό όνομα. Αν λείπει, χρησιμοποιείται το όνομα PC. |
| Computer / Windows user | Όνομα υπολογιστή και χρήστη που ανέφερε ο Client. |
| Group | Ομάδα Client ή Ungrouped. |
| Client code | Μοναδικός κωδικός, χρήσιμος και στην CLI. |
| Last seen | Τελευταία αναφορά, σε τοπική ώρα με UTC offset. Το JSON κρατά την αρχική ημερομηνία Server. |
| Live connection | Connected, Disconnected ή Not reported, σύμφωνα με τα metadata του Server. |
| Online / Offline / Unknown | Τελευταία κατάσταση Client. |
| Stale | Η σύνδεση Dashboard χάθηκε· τα στοιχεία μπορεί να είναι παλιά και οι αποστολές απενεργοποιούνται. |
| Application versions | Οι τελευταίες εκδόσεις που ανέφερε ο Client. `—` σημαίνει μη διαθέσιμη τιμή. |
| Client name | Φιλικό όνομα προς αποθήκευση. Δεν αλλάζει το hostname των Windows. |
| Security | Reset της ταυτότητας σύνδεσης. Η πραγματική τιμή token δεν εμφανίζεται. |

Οι ενημερώσεις metadata δεν διαγράφουν ένα μη αποθηκευμένο draft ονόματος. Αν το αποθηκευμένο όνομα αλλάξει, το Revert χρησιμοποιεί την τελευταία επιβεβαιωμένη τιμή.

## Συντομεύσεις
| Συντόμευση | Ενέργεια |
| --- | --- |
| Ctrl+L | Εστίαση στο πεδίο ονόματος. |
| Ctrl+S / Enter στο όνομα | Αποθήκευση νέου ονόματος. |
| Esc στο όνομα | Revert. |
| Ctrl+Shift+C | Copy details. |
| Ctrl+Shift+R | Άνοιγμα επιβεβαίωσης reset token. |
| Ctrl+C σε metadata | Αντιγραφή επιλεγμένου κειμένου. |
| Esc στο dialog | Ακύρωση reset χωρίς αποστολή. |

Οι συντομεύσεις του Overview ισχύουν όταν η εστίαση βρίσκεται μέσα σε αυτή την καρτέλα.

## CLI / CMD
Από τον φάκελο `dashboard`:

```powershell
python -m app.overview_cli --client CLIENT_CODE
python -m app.overview_cli --client CLIENT_CODE --rename "Κατάστημα Αθήνας"
python -m app.overview_cli --client CLIENT_CODE --reset-token --confirm RESET
python -m app.main --overview --client CLIENT_CODE
```

Με το console EXE:

```bat
MoonHardRemoteOverview.exe --help
MoonHardRemoteOverview.exe --client CLIENT_CODE > overview.json
MoonHardRemoteOverview.exe --client CLIENT_CODE --rename "Shop Athens"
MoonHardRemoteOverview.exe --client CLIENT_CODE --reset-token --confirm RESET
```

Η CLI χρησιμοποιεί τις υπάρχουσες ρυθμίσεις Dashboard. Γράφει UTF-8 JSON και logs στο stderr. Το reset απορρίπτεται πριν από σύνδεση αν λείπει `--confirm RESET`. Περιμένει μέχρι 30s για αποτέλεσμα μετά την αυθεντικοποίηση. Κωδικοί εξόδου: `0` επιτυχία, `1` αποτυχία, `130` διακοπή χρήστη. Η διακοπή CLI δεν αναιρεί αποσταλμένο rename ή reset.

## Πότε χρησιμοποιείται / δεν χρησιμοποιείται
Χρησιμοποιείται για έλεγχο Client, εκδόσεων, ταυτότητας και φιλικού ονόματος. Δεν διαχειρίζεται ομάδες, εγκαταστάσεις εφαρμογών, δικαιώματα SQL ή Windows accounts. Δεν διαβάζει νέα στοιχεία απευθείας από offline υπολογιστή.

## Έλεγχοι πριν και μετά
Πριν: ελέγξτε τίτλο Manage, Client code, σύνδεση Dashboard και αν χρειάζεται πραγματικά reset.
Μετά: επιβεβαιώστε μήνυμα επιτυχίας, αποθηκευμένο όνομα ή επανασύνδεση Client. Ελέγξτε ότι το draft δεν άλλαξε μετά από heartbeat.

## Αντιμετώπιση προβλημάτων
| Πρόβλημα | Ενέργεια |
| --- | --- |
| Κενή έκδοση / `—` | Περιμένετε νέα αναφορά από online Client. |
| Stale / κουμπιά ανενεργά | Ελέγξτε τη σύνδεση Dashboard και περιμένετε reconnect. |
| Το όνομα δεν αλλάζει | Ελέγξτε validation και αποτέλεσμα αποθήκευσης. Το draft δεν θεωρείται αποθηκευμένο. |
| Λήξη αναμονής | Ελέγξτε το αποθηκευμένο όνομα ή την κατάσταση Client πριν επαναλάβετε. |
| Το reset δεν αποστέλλεται | Πληκτρολογήστε ακριβώς RESET και ελέγξτε σύνδεση Dashboard. |
| Client παραμένει offline | Ελέγξτε τον Client και τη σύνδεσή του με Server. |

## Συνηθισμένα λάθη
Σύγχυση φιλικού ονόματος με hostname, θεώρηση παλαιών εκδόσεων ως τρέχουσες, χρήση reset για απλό rename και επανάληψη ανεπιβεβαίωτης ενέργειας χωρίς έλεγχο.

## Βέλτιστες πρακτικές
Χρησιμοποιήστε αναγνωρίσιμα ονόματα. Αντιγράψτε Client code για CLI. Ελέγχετε Last seen όταν ο Client είναι offline. Οι νέες ενέργειες καταγράφονται χωρίς tokens ή τιμές metadata.

## Σημειώσεις για μελλοντικές αλλαγές
Presenter, UI, CLI και έλεγχοι EXE είναι χωριστά modules. Διατηρήστε τη ρητή λίστα ασφαλών πεδίων, την προστασία draft, τη συσχέτιση Client και τη δοκιμή όλων των Manage tabs μετά από αλλαγές διάταξης.
